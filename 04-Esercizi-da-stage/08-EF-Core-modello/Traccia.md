# Modello dati per Entity Framework Core

**File da creare:** `Product.cs`  
**Tipo consigliato:** ASP.NET Core con Entity Framework Core

## Scenario

Un catalogo necessita di prodotti e categorie collegati, con dati pronti per essere persistiti tramite EF Core.

## Traccia

- Definisci le entità Product e Category con chiavi e proprietà appropriate.
- Rappresenta la relazione uno-a-molti e le proprietà di navigazione.
- Aggiungi validazioni e lunghezze coerenti per i dati del catalogo.

## Bonus

Descrivi nella traccia della tua soluzione quali vincoli configureresti con Fluent API nel DbContext.

## Criteri di completamento

- La soluzione rispetta i requisiti e usa nomi chiari.
- Gli input e i casi limite sono gestiti esplicitamente.
- La soluzione è stata provata con almeno un caso valido e uno non valido, dove applicabile.
