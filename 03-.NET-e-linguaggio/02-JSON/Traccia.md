# Salvataggio di impostazioni JSON

**File da creare:** `Program.cs`  
**Tipo consigliato:** Console, salvo diversa indicazione

## Scenario

Un'applicazione conserva le proprie impostazioni in un file JSON e le ricarica al successivo avvio.

## Traccia

- Definisci una classe di impostazioni con proprietà tipizzate.
- Serializza e deserializza usando System.Text.Json.
- Gestisci file assente o JSON non valido senza sovrascrivere dati in modo silenzioso.

## Bonus

Aggiungi valori predefiniti e documenta quando vengono applicati.

## Criteri di completamento

- La soluzione rispetta i requisiti e usa nomi chiari.
- Gli input e i casi limite sono gestiti esplicitamente.
- La soluzione è stata provata con almeno un caso valido e uno non valido, dove applicabile.
