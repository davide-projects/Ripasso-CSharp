# Percorso di ripasso C# e .NET

Percorso modulare di esercitazione, dal C# fondamentale fino a .NET, ASP.NET Core MVC ed Entity Framework Core, in linea con il manuale **C# e .NET da zero a MVC con Entity Framework Core**.

## Come usarlo

- Segui le cartelle numerate; ogni esercizio ha una propria cartella e una `Traccia.md`.
- Il nome del file sorgente da creare è indicato all'inizio della traccia. **I file `.cs` non sono stati creati**: aggiungili tu nella cartella dell'esercizio.
- Per gli esercizi fino a `03-.NET-e-linguaggio`, crea un progetto Console e aggiungi il sorgente indicato. Per le tracce MVC/EF Core, crea o usa un progetto ASP.NET Core adatto e inserisci la classe indicata nel progetto.
- Prova a risolvere la traccia prima di consultare appunti o soluzioni; poi prova i casi limite e l'esercizio bonus.
- Le tracce da stage sono esercizi autonomi: non richiedono credenziali, servizi aziendali o dati reali.

## Moduli

| Cartella | Contenuti |
|---|---|
| `00-Basi` | Sintassi, input/output, tipi, operatori, parsing, condizioni, cicli, metodi e stringhe |
| `01-Strutture-dati` | Array, matrici, liste, dizionari, ricerca e ordinamento |
| `02-Programmazione-a-oggetti` | Classi, costruttori, incapsulamento, static, enum, ereditarietà, polimorfismo, interfacce, eccezioni e generics |
| `03-.NET-e-linguaggio` | File, JSON, LINQ, lambda/delegati, nullable, async/await e HTTP |
| `04-Esercizi-da-stage` | Gestione dati, importazione CSV, log, API REST, MVC, EF Core e test unitari |

Ogni `Traccia.md` contiene scenario, requisiti e un'estensione facoltativa. Le tracce MVC ed EF Core sono pensate per essere svolte dentro un progetto ASP.NET Core, non come programmi Console autonomi.
